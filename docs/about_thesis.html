Quantum Computing Bachelor's Thesis

My bachelor's thesis was titled "Adaptively measuring quantum expectation values using the empirical Bernstein stopping rule".

The aim was to estimate quantum expectation values accurately while keeping the number of measurement shots low. Rather than fixing the sample count in advance, the stopping rule uses the observed data to decide when enough measurements have been collected.

Overview

This thesis was advised by Alexander Gresch and Martin Kliesch. The accompanying empirical Bernstein algorithm in Python implements the adaptive sampling method.

We studied an application of the empirical Bernstein stopping rule[1] (EBS) in quantum computing. See the reference below for the original paper. PDF · 399 kB

\[ \left|\overline{X}_t - \mu\right| \leq \overline{\sigma}_t\,\sqrt{\frac{2\ln(3/\delta)}{t}} + \frac{3R\,\ln(3/\delta)}{t}. \]

Here, \(\overline{X}_t\) is the empirical mean, \(\mu\) is the true mean, \(\overline{\sigma}_t\) is the empirical standard deviation, \(R\) is the range of the random variable, \(t\) is the number of samples, and \(\delta\) is the confidence parameter.

The goal was to estimate quantum expectation values with a required accuracy \(\epsilon\) and confidence \(1 - \delta\) while minimizing the number of measurement shots.

The figure below compares EBS with a sampling bound based on Hoeffding's inequality for estimating the ground-state energy of NH3. We set the accuracy \(\epsilon\) to chemical accuracy, i.e. \(0.0016\,\mathrm{Ha}\). In this example, EBS requires fewer samples to reach the target accuracy.
